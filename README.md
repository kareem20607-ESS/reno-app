# reno-app

واجهة RENO STORE الخاصة (تجربة المرحلة ١): الرئيسية، الكتالوج، تفاصيل المنتج، والمسح بالكاميرا.

- صفحات ثابتة من غير خطوة بناء: `index.html` + `css/` + `js/`.
- المستودع ده مفيهوش أي بيانات ولا مفاتيح. البيانات بتتقري بعد الدخول بحساب جوجل من سكريبت قراءة منفصل.
- `js/config.js`: معرّف دخول جوجل ورابط سكريبت القراءة. وهما فاضيين التطبيق بيشتغل ببيانات عيّنة.
- الخطوط (Tajawal و Playfair Display) مستضافة في `fonts/` برخصة SIL OFL، وقارئ الباركود الاحتياطي `vendor/zxing.min.js` (ZXing، رخصة Apache-2.0).
